# Team Mewpilot house rules (global instructions template)
#
# Copy this file's contents into your global Copilot CLI instructions
# (ask Copilot: "Where do you look for global instructions on this
# machine?" if you're not sure where that is) to apply these rules to
# every project you open, not just copilot-cli-lab.

- Always use conventional commits (feat:, fix:, chore:) in commit messages.
- Prefer small, incremental diffs over large rewrites.
- Never delete tests without explicit approval.
- When unsure between two reasonable approaches, ask instead of guessing.
